Multiplet labels appear first in the subscript group: $`\rho_1`$, $`\lambda_1^i`$,
$`\lambda_{1i}`$, $`Y_1^{ij}`$, $`Y_{1ij}`$, and $`A_{1\mu}`$.
The same label on the same field denotes the same multiplet across files;
earlier superscript or subscript placement does not define another multiplet.

```math
\boxed{
\begin{aligned}
e^{-1}\mathcal L_{V_1L_1}
={}&Y_1^{\,ij}L_{1ij}
+\rho_1N_1
+i\bar\lambda_1^{\,i}\varphi_{1i}
+\frac12\widehat F_{1ab}E_1^{ab}\\
&-\frac12L_{1ij}\bar\psi_a^{\,i}\gamma^a\lambda_1^{\,j}
+\frac12\rho_1\bar\psi_a^{\,i}\gamma^a\varphi_{1i}
+\frac12E_1^{ab}\bar\psi_a^{\,i}\gamma_b\lambda_{1i}\\
&+\frac{i}{4}\rho_1L_{1ij}\bar\psi_a^{\,i}\gamma^{ab}\psi_b^{\,j}
-\frac{i}{4}\rho_1E_1^{ab}\bar\psi_a^{\,i}\psi_{bi}.
\end{aligned}
}
```
