# Gauss–Bonnet on AdS₅: action inputs

The analysis selects the AdS₅ branch that continuously approaches the two-derivative AdS₅ vacuum as the Gauss–Bonnet coupling tends to zero. Its quadratic analysis uses the following component action, with the source normalization retained:

```math
S=(2\kappa_5^2)^{-1}\int e[\ell_{2\partial}+\lambda_{\rm GB}(-2\ell_{W,OP}-4\ell_{\log})]_{\le2}.
```

## Relation to the common action basis

The [common-basis GB combination](common_basis.md) classifies the invariant with the shared Weyl² and LOG building blocks. Its coupling convention is distinct from the input used for Gauss–Bonnet on AdS₅ above. The bosonic, covariant-core and explicit two-fermion tables linked there describe that common basis; they are not substituted for the component expression used in this AdS₅ calculation.
