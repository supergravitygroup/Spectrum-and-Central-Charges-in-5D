# Gauss–Bonnet supergravity

The theory combines the gauged two-derivative action with the Gauss–Bonnet invariant. The action includes the bosonic density and terms through two physical fermions.

| Other backgrounds and selected-sector results | [Fluxed products $`M^3\times\Sigma^2`$](product_backgrounds/README.md) |

Use the [common conventions](../common/conventions.md) and [field dictionary](../common/fields_and_derivatives.md) together with the source conventions attached to the action.

The analysis selects the AdS₅ branch that continuously approaches the two-derivative AdS₅ vacuum as the Gauss–Bonnet coupling tends to zero. Its component action and coupling normalization are specified in [the input definition](ads5/action_inputs.md).

[Theory-specific notation](notation.md).

The product-background material has a different scope from the AdS₅ spectrum:
it provides local background equations and selected quadratic and supersymmetry
analyses. It does not supply a complete physical spectrum on those products.
