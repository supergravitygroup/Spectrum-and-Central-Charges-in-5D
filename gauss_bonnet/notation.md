# Gauss–Bonnet: notation across the action and spectrum

The component derivations retain their source-local symbols. The following dictionary fixes the reading correspondence.

| Symbol | Meaning in the Gauss–Bonnet on AdS₅ calculation |
|---|---|
| $`\lambda_{\rm GB}`$ | Coupling of the component action used for Gauss–Bonnet on AdS₅ |
| $`\lambda`$ in the common-basis classification | Separate common-basis GB coupling; no full component equivalence is asserted |
| $`x=L_0`$ | Background compensator |
| $`\mathcal L`$ | AdS radius, distinct from the scalar field $`L`$ |
| $`\zeta`$ | Spinor field, not the R² coupling |
| $`a`$, $`c`$ | Branch combinations defined in the Gauss–Bonnet on AdS₅ spectrum |

The [Action input for Gauss–Bonnet on AdS₅](ads5/action_inputs.md) fixes the source normalization. The common-basis classification is a separate comparison, not the action input of the Hessian used for Gauss–Bonnet on AdS₅.
