# Gauss–Bonnet on AdS₅

[Notation dictionary](../notation.md).

The analysis selects the AdS₅ branch that continuously approaches the two-derivative AdS₅ vacuum as the Gauss–Bonnet coupling tends to zero. The calculation uses the complete component action through two physical fermions. Its local spectrum and kinetic weights are given with the source normalization.
