# Weyl²: notation across the action and spectrum

The component derivations retain their source-local symbols. The following dictionary fixes the reading correspondence.

| Common presentation | Derivation notation | Meaning |
|---|---|---|
| $`\alpha`$ | $`\alpha`$ | Weyl² coupling |
| $`\rho_W`$ | $`\rho`$ | Spectral root parameter |
| $`m_W`$ | $`m`$ | Internal fermion mass matrix |
| $`\ell_5`$ | $`\ell`$ | AdS5 radius |
| Scalar fluctuation | $`\lambda`$, $`\lambda_{\rm s}`$ | Field amplitudes; not the Weyl² coupling |

The [physical-operator definitions](ads5/details/physical_operators.md) define $`m`$, $`\rho`$, $`\nu`$, $`\kappa`$ and the eigenfields. The [quadratic action](ads5/quadratic_action.md) defines the wave operators used in the tables.
