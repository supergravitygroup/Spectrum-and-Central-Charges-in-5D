# Fermionic sample results and operator matrices

This index connects every sample in the [combined table](table.json) to its
complete spectrum, mode matching and eight sector operators. The first twelve
samples are the nonzero-coupling points in paper Table 12; the remaining six
are the stated two-derivative limits. See the [calculation guide](../README.md)
for the matrix bases, coefficient encoding and numerical scope.

Each sector file contains the ordered bases, all coefficients of the operator
polynomial, its retained roots and numerical rank diagnostics. The combined
sample file contains the charge-preserving comparison with the bosonic prediction.
