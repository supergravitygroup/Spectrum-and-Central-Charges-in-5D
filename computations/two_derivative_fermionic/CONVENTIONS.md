# Conventions

| Object | Working definition |
|---|---|
| Dimension and signature | $`D=5`$, $`\eta=(-++++)`$; $`a,\mu=0,\ldots,4`$ |
| SU(2) | $`i,j=1,2`$, $`\epsilon_{12}=\epsilon^{12}=1`$; $`X^i=\epsilon^{ij}X_j`$, $`X_i=X^j\epsilon_{ji}`$ |
| Spinor bar | Operational Majorana bar $`\bar\psi=\psi^T C`$; scalar $`i`$ is not complex-conjugated |
| Fermions | Grassmann-odd symplectic Majorana; a fixed-index flip differs from an NW–SE contraction flip |
| Clifford | $`\{\gamma_a,\gamma_b\}=2\eta_{ab}`$; antisymmetrization has unit weight |
| Curvature | $`[\bar\nabla_\mu,\bar\nabla_\nu]\zeta=\bar R_{\mu\nu}{}^{ab}\gamma_{ab}\zeta/4`$ |
| Background | $`L_0=1`$, $`N_0=-3g/2`$, $`k=-g^2/2=-\ell^{-2}`$; $`g\ne0`$ |
| Gauge | $`\sigma=1`$, $`b_\mu=0`$, dilatino $`\psi^i=0`$, $`L_{ij}=L\delta_{ij}/\sqrt2`$, $`L>0`$ |
| Retained fermions | Gravitino $`\psi_\mu^i`$ and linear multiplet fermion $`\varphi^i`$ |
| Density | $`-2\mathcal L_\mathrm{VL}[V_\mathrm{linear}+2gV_\mathrm{defining};\mathbb L]`$ |
| Perturbation | $`S=S^{(0)}+tS^{(1)}+t^2S^{(2)}+\cdots`$; no extra $`1/2!`$ |
| Equality | $`\doteq`$ denotes equality up to the stated covariant boundary term |

Fixing a field does not fix its derivatives: $`\mathcal D_\mu\psi^i`$ and
$`\square^C\sigma`$ retain connection contributions after gauge fixing. $`L`$ is dynamical.
Ordinary $`F`$ and supercovariant $`\widehat F`$ are kept distinct; the BF
field-strength representative uses ordinary $`F`$.

The density's overall factor-two normalization is an input calibrated against
the Einstein $`LR`$ coefficient. The relative $`2g`$ vector addition follows from
the defining-vector Euler reduction; auxiliary-field EOMs of the target theory
are not used to construct the nonlinear action.

Absolute masses and $`\ell^2=2/g^2`$ are independent of the sign of g.
The source charge formulae use the $`g>0`$ orientation; reversing $`g`$ exchanges
the two conjugate charge branches. They constitute one symplectic-Majorana field
and are not counted twice.
