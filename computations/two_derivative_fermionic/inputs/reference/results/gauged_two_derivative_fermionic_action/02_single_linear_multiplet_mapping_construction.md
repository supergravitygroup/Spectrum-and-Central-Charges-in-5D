## 3. Convention ledger

The project uses the NW–SE convention

```math
A^i=\varepsilon^{ij}A_j,
\qquad
A_i=A^j\varepsilon_{ji},
\qquad
\varepsilon_{12}=\varepsilon^{12}=1.
```

Consequently,

```math
\varepsilon^{ij}\varepsilon_{jk}=-\delta^i{}_k,
\qquad
\varepsilon^{ij}\varepsilon_{kj}=+\delta^i{}_k.
```

The linear-multiplet scalar is symmetric,

```math
L_{ij}=L_{ji},
\qquad
L^{ij}=\varepsilon^{ik}\varepsilon^{j\ell}L_{k\ell}.
```

Because $`L_{ij}`$ is a symmetric variable, differentiation with respect to
it is defined by

```math
\frac{\partial L_{k\ell}}{\partial L_{ij}}
=
\delta_k{}^{(i}\delta_\ell{}^{j)}
=
\frac12
\left(
\delta_k{}^i\delta_\ell{}^j
+
\delta_k{}^j\delta_\ell{}^i
\right).
```

The multiplet labels $`A,B,\ldots`$ are not $`SU(2)`$ indices.  Restricting
them to the value 1 causes no raising or lowering operation.

## 4. Definitions and required identities

### 4.1 Source derivative definitions

Özkan Eq. (2.6) defines

```math
\mathcal F_{ABC}^{ij}
=
\frac{\partial\mathcal F_{AB}}{\partial L^C_{ij}},
```

and

```math
\mathcal F_{ABCD}^{ij\,km}
=
\frac{\partial^2\mathcal F_{AB}}
{\partial L^C_{ij}\,\partial L^D_{km}}.
```

For one multiplet these become ordinary repeated derivatives of
$`L^{-1}`$ with respect to the symmetric components $`L_{ij}`$.

### 4.2 Derivative of the raised scalar

Start from

```math
L^{ij}=\varepsilon^{ik}\varepsilon^{j\ell}L_{k\ell}.
```

Differentiation gives

```math
\begin{aligned}
\frac{\partial L^{ij}}{\partial L_{km}}
&=
\varepsilon^{ip}\varepsilon^{jq}
\frac{\partial L_{pq}}{\partial L_{km}}
\\
&=
\varepsilon^{ip}\varepsilon^{jq}
\delta_p{}^{(k}\delta_q{}^{m)}
\\
&=
\frac12
\left(
\varepsilon^{ik}\varepsilon^{jm}
+
\varepsilon^{im}\varepsilon^{jk}
\right).
\end{aligned}
```

This is only the algebraic Jacobian for a symmetric $`SU(2)`$ tensor; it is
not a newly defined field or differential operator.

### 4.3 Derivative of the norm

Differentiate the defining relation

```math
L^2=L_{k\ell}L^{k\ell}.
```

Using the product rule,

```math
\begin{aligned}
\frac{\partial L^2}{\partial L_{ij}}
&=
\frac{\partial L_{k\ell}}{\partial L_{ij}}L^{k\ell}
+
L_{k\ell}\frac{\partial L^{k\ell}}{\partial L_{ij}}
\\
&=L^{ij}+L^{ij}
\\
&=2L^{ij}.
\end{aligned}
```

On the branch $`L\neq0`$, the chain rule gives

```math
2L\frac{\partial L}{\partial L_{ij}}=2L^{ij},
```

hence

```math
\boxed{
\frac{\partial L}{\partial L_{ij}}
=L^{-1}L^{ij}.
}
```

For any real power $`p`$,

```math
\boxed{
\frac{\partial L^{-p}}{\partial L_{ij}}
=-pL^{-p-2}L^{ij}.
}
```

This identity will be used repeatedly below.

### 5.6 General derivative pattern

At derivative order $`n`$, choose $`k`$ disjoint pairs among the $`n`$
derivative index-pairs.  Each chosen pair is represented by the corresponding
symmetric Jacobian

```math
\frac12
\left(
\varepsilon^{i_a i_b}\varepsilon^{j_a j_b}
+
\varepsilon^{i_a j_b}\varepsilon^{j_a i_b}
\right),
```

and every unpaired derivative index-pair contributes one factor of
$`L^{i_cj_c}`$.  Summing over inequivalent disjoint pairings gives

```math

{\partial L_{i_1j_1}\cdots\partial L_{i_nj_n}}
```

## 6. Calligraphic versus non-calligraphic tensors

These two families must not be confused.

### 6.1 Source Eq. (2.17)

For one linear multiplet, Özkan Eq. (2.17) reduces to

```math
F_{11}
=
2\mathcal F_{11}
+\mathcal F_{111}^{ij}L_{ij},
```

```math
F_{111}^{ij}
=
3\mathcal F_{111}^{ij}
+\mathcal F_{1111}^{ij\,km}L_{km},
```

and

```math
F_{1111}^{ij\,km}
=
4\mathcal F_{1111}^{ij\,km}
+\mathcal F_{11111}^{ij\,km\,pq}L_{pq}.
```

### 6.2 Required homogeneity contractions

Because $`L_{ij}`$ has Weyl weight 3 and $`\mathcal F_{11}`$ has weight
$`-3`$, Euler homogeneity gives

```math
L_{ij}\mathcal F_{111}^{ij}=-\mathcal F_{11}.
```

Differentiate this identity once:

```math
\begin{aligned}
\frac{\partial}{\partial L_{km}}
\left(L_{ij}\mathcal F_{111}^{ij}\right)
&=
\frac{\partial}{\partial L_{km}}
\left(-\mathcal F_{11}\right)
\\
\mathcal F_{111}^{km}
+L_{ij}\mathcal F_{1111}^{ij\,km}
&=-\mathcal F_{111}^{km}.
\end{aligned}
```

Therefore

```math
L_{ij}\mathcal F_{1111}^{ij\,km}
=-2\mathcal F_{111}^{km}.
```

Differentiate once more:

```math
\begin{aligned}
\mathcal F_{1111}^{pq\,km}
+L_{ij}\mathcal F_{11111}^{ij\,km\,pq}
&=-2\mathcal F_{1111}^{km\,pq},
\end{aligned}
```

so pair symmetry yields

```math
L_{ij}\mathcal F_{11111}^{ij\,km\,pq}
=-3\mathcal F_{1111}^{km\,pq}.
```

### 6.3 Evaluation of the non-calligraphic tensors

Substitute the first contraction into $`F_{11}`$:

```math
\begin{aligned}
F_{11}
&=2\mathcal F_{11}-\mathcal F_{11}
\\
&=\mathcal F_{11}
\\
&=L^{-1}.
\end{aligned}
```

For the first descendant,

```math
\begin{aligned}
F_{111}^{ij}
&=3\mathcal F_{111}^{ij}
-2\mathcal F_{111}^{ij}
\\
&=\mathcal F_{111}^{ij}
\\
&=-L^{-3}L^{ij}.
\end{aligned}
```

For the second descendant,

```math
\begin{aligned}
F_{1111}^{ij\,km}
&=4\mathcal F_{1111}^{ij\,km}
-3\mathcal F_{1111}^{ij\,km}
\\
&=\mathcal F_{1111}^{ij\,km}.
\end{aligned}
```

Hence

```math
\boxed{
\begin{aligned}
F_{11}&=\mathcal F_{11}=L^{-1},
\\
F_{111}^{ij}
&=\mathcal F_{111}^{ij}=-L^{-3}L^{ij},
\\
F_{1111}^{ij\,km}
&=\mathcal F_{1111}^{ij\,km}
\\
&=
3L^{-5}L^{ij}L^{km}
-\frac12L^{-3}
\left(
\varepsilon^{ik}\varepsilon^{jm}
+\varepsilon^{im}\varepsilon^{jk}
\right).
\end{aligned}
}
```

The equality of the calligraphic and non-calligraphic tensors is a special
consequence of the one-multiplet homogeneous choice.  It must not be assumed
for a general multi-multiplet function.

### 11.3 Epsilon-trace condition, Eq. (2.10)

Contract the second derivative with $`\varepsilon_{jk}`$:

```math
\begin{aligned}

={}&

&-

```

The first contraction is


The epsilon contraction in the second line is

```math

\left(
```

```math

\end{aligned}
```

Thus the source condition (2.10) is satisfied.
