## 1. Anchored statement

For the single linear multiplet used in this project, the completed local
map is

```math
\boxed{
\left(L_{ij},\varphi_i,E_a,N\right)
\longmapsto
\left(\rho,\lambda_i,Y_{ij},\widehat F_{\mu\nu}\right).
}
```

The four quantities on the right are the components of the vector multiplet
constructed from the linear multiplet. They are the **linear-map slots** to
be inserted as the vector argument of the complete vector--linear density
when the two-derivative action is constructed.

This map is not the defining vector multiplet. In particular, the
linear-to-vector composite slot $`Y_{ij}`$ is not the defining-vector
auxiliary $`Y^{ij}`$. Any later sum involving the defining vector must first
display the linear map and the defining vector separately and must derive the
sum from the applicable source construction.

general Özkan construction take the value

```math

```

```math

\qquad
```

equation, Poincaré gauge, gauging deformation, integration by parts, or
background restriction was used.

```math
A^i=\varepsilon^{ij}A_j,
\qquad
A_i=A^j\varepsilon_{ji},
\qquad
\varepsilon_{12}=\varepsilon^{12}=1.
```
