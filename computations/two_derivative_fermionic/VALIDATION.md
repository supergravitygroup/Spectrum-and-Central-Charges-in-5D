# Verification scope

The [package guide](README.md) identifies the supplied component inputs and
calculation stages. Exact coefficient collection verifies algebra within those
inputs; it does not by itself prove nonlinear supersymmetry of an adopted map.

Use the [repository reproduction commands](../../README.md#reproduction) for the
current paper calculations. [Repository validation](../../tools/validate_repository.py)
checks local links, Python syntax and file integrity separately.
