# Two-derivative action

## Recomputed outer BF insertion

The following terms sum to the density after effective-slot substitution. Retained Y, lambda and F components include supercovariant completions. The ordered-word calculation is not an elementary expansion of every Pauli term.

```math
- \sqrt{2} L \delta^{ij}Y_{\mathrm{linear}\,ij}
```

```math
\frac{2 \left(L^{3} g^{2} - 2 L N g - 2 N^{2}\right)}{L} 
```

```math
- 2 i \bar\lambda_{\mathrm{linear}}{}^i\varphi_i
```

```math
\frac{\sqrt{2} L}{2} \delta_{ij}\bar\psi_a{}^i\gamma^a\lambda_{\mathrm{linear}}{}^j
```

```math
-1 F_{\mathrm{linear}\,\mu\nu} E^{\mu\nu}
```

```math
- 2 g G_{\mu\nu} E^{\mu\nu}
```

```math
- \frac{\sqrt{2} i N}{L^{2}} \delta_{ij}\bar\varphi^i\varphi^j
```

```math
- \frac{2 \left(L g + N\right)}{L} \bar\psi_a{}^i\gamma^a\varphi_i
```

```math
- \frac{\sqrt{2} i \left(L g + N\right)}{2} \delta_{ij}\bar\psi_a{}^i\gamma^{ab}\psi_b{}^j
```
