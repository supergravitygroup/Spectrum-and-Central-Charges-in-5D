The [retained certificate](../../../../../../../../../references/source_evidence/log/results/gauged_full_fermionic_log/sources/certification_20260925/defining_projector/certification.json) records the final sector comparisons and negative control. The original replay scripts, temporary pickle intermediates and superseded diagnostic logs are not included in this repository. The [component evidence guide](../../../../../../../../../references/source_evidence/README.md) describes the retained programs and their input dependencies.

The primary/linear projector source is [Butter et al., arXiv:1410.8682v2](https://arxiv.org/abs/1410.8682v2), §§7.1 and 14.3; the derivation above states the inhomogeneous logarithmic dilatation shift.

The final proof is an exact local identity modulo the complete curved conformal algebra. It does not discard a boundary term, fix the compensator, assume a flat background or eliminate an auxiliary field.
