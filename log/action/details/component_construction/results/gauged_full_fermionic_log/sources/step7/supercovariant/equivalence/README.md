# Covariant component comparison

The [component comparison](../../../../../../../../../../references/source_evidence/log/results/gauged_full_fermionic_log/sources/step7/supercovariant/equivalence/decisive_comparison.json) evaluates the four LOG components after the composite map and gauge evaluation. Exact tensor/Clifford reduction, five-dimensional Schouten identities and the conventional gamma-trace projector give zero final coefficient residuals.

The calculation keeps ordered full covariant derivatives and the specified fermion degree. It assumes no symmetry of the full dependent connection or primed Ricci tensor, and uses no integration by parts or field equations. Nonzero intermediate residual counts precede the final identity reductions.

The supporting standalone script is not included; the local record and the [derivation](../derivation.md) specify the comparison and its scope.
